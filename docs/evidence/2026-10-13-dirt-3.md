# DiRT 3 Complete Edition on Vulkan, 16:9 (PLA-24)

**Linear:** [PLA-24](https://linear.app/playportdev/issue/PLA-24) (compat speedrun, PLA-112).

No code change. IPA sha256 `7e95a2c083c6d74f65be5ded7df5a0b22b4ecf31ff2b90c4b74c09e5462c8948`
(dev, 0feacb2; the `installed` event), Apple A19 Pro, iOS 27.0.

## The copy and its import

DiRT 3 Complete Edition (Steam 321040, delisted; 32-bit x86, EGO engine) as a Local import: a
15.0 GB game folder copied from the workstation into `Documents/Import` over AFC (14,382 entries,
595 s over the network), then `pp ui --action import:…` (an APFS clone: in the library after 13.9 s,
`dir-dirt 3 complete edition`), then the folder in `Documents/Import` removed.

The import picked `Dirt3FovChange.exe` as the executable: `Adoption.pick` takes the first
executable by name when none is named like the folder, and `Dirt3FovChange.exe` sorts before
`binXml.exe` and `dirt3_game.exe` (a plain Steam copy would get `binXml.exe` the same way). The
game page's Game options › Executable picker, walked with pad presses, set `dirt3_game.exe`
(`library: executable of dir-dirt 3 complete edition: dirt3_game.exe`).

No prerequisite ran on the Play (none logged; the folder ships `_CommonRedist` installscripts for
VC++ 2010 and OpenAL). The game loaded `C:\windows\system32\OpenAL32.dll` (the prefix's) and
Wine's d3d9/d3d11 (DXVK); DirectX setup is not involved.

## Runs

`pp ui --settings 'dir-dirt 3 complete edition:{"graphics":"vulkan","aspect":"16:9"}' --play 'dir-dirt 3 complete edition' --until first-frame+30 --shot --screenshot-after 60 --wait 180`
(run `20261013T085855`): runtime started +2.99 s, game started +3.25 s, first frame +3.95 s;
stop at first frame + 30 (`until_reached: true`, exit 0). The game takes its Direct3D 11 path
(DXVK 3.1.1 x86, `D3D11DXGIDevice` lines; d3d9.dll is also loaded for its device probe). Its
audio stream opens (`create_stream by 'DiRT3'`, 48 kHz float). The stop screenshot and the one
at +60 s show the animated title screen (the big "3" logo, a different camera angle in each) with
the "press Start or Enter" prompt, letterboxed in the 16:9 frame. The prompt is in Russian: this
copy's own language setting, not Playport's.

One `pp phone lock` session (run `20261013T090113`): the same play with `--pad --leave-running
--until first-frame+25`, then three `pp pad send '150 A' …` presses with a screenshot after each:
a dark intro scene, then the front end's rally car scene, then the New Profile menu (name, surname,
sex, nationality, continue) over the car scene. The game takes pad input; the run ended with
`pp phone kill`.

Status: Playable with issues. The game itself starts on Vulkan to its title screen and front-end
menus; a Local import of it needs two things a player should not have to know: the Executable set
to `dirt3_game.exe`, and an OpenAL32.dll in the prefix. Here OpenAL32 was already there from another
title's OpenAL redistributable (the prefix's prerequisite record: "Open AL (2.0.7.0)", run for
Baldur's Gate: EE); a Local title does not run the `_CommonRedist` installscripts its folder ships
(LibraryModel runs a Steam title's), so on a fresh prefix the import would miss it.

Not checked: a race, performance, the game's D3D9 mode (`forcedx9` in its hardware settings),
sound on a speaker.
