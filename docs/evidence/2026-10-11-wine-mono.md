**Date:** 2026-10-11. **Linear:** [PLA-125](https://linear.app/playportdev/issue/PLA-125)
(this work); [PLA-113](https://linear.app/playportdev/issue/PLA-113) and
[PLA-67](https://linear.app/playportdev/issue/PLA-67) (House of Golf 2's prerequisite
installer). Decision [0077](../decisions/0077-ship-wine-mono.md).

Dev IPA `4728a51584978d192716e12d53ef5f8d59453661c37ab9d671cfeb10cf6a62b6` (Wine Mono 11.3.0
in `Runtime/mono`, the `WINE_MONO` registry seed), installed as an in-place upgrade over
`e83de2458f8a1dc46817ff076b9dd6329fb58f5c4bf4e76c7f5a544cef9aa134`, whose prefix had no .NET
keys, for every run below but the last section; then the same tree built from commit 1a10332,

their signatures and profiles), for the checks in "On the committed IPA". Run directories are
under `$PLAYPORT_BUILD/agent-notes/pla125/`.

## What ships

WineHQ's `wine-mono-11.3.0-x86.tar.xz` (sha256 `54a1b011…d298`), the version the wine pin's
`mscoree` names (`WINE_MONO_VERSION "11.3.0"`), byte-identical to Proton Experimental's
`share/wine/mono/wine-mono-11.3.0` (`diff -r`: no difference). 2,790 files and 156 links, staged
as 2,946 files, 276.6 MiB. The dev IPA grew from 287,384,777 to 394,577,367 bytes.

## A .NET 4 program

`hello64.exe` and `hello32.exe`: one C# file built with the release's own `mcs.exe`
(`-sdk:4.5 -target:winexe`, `-platform:x64` and `-platform:x86`) under desktop Wine. It
writes `hello-result.txt` beside itself, shows a WinForms window with the same text and
closes it after 30 s with exit code 42. Under desktop Wine both print `Hello from .NET
4.0.30319.42000 on 6.13.0 (tarball)`, 64-bit and 32-bit. On the phone each was a Local title
(`dir-mono test 64`, `dir-mono test 32`).

**x86-64: runs** (`run-mono64`, `run-mono64-shot`). `mscoree` found the shipped tree with no
patch; Mono loaded its assemblies:

Vulkan, 16:9 (`run-uepre`). The prefix got the seed's keys at the first launch of the new
IPA (its `system.reg` after the runs has `NDP\v4\Full` with `Install`=1, `Release`=0x82348).
